# Synopsis — ham-mintsauce Rebuild (2026-09-05)

**Total time spent: approximately 3 hours 45 minutes** (~15:03–18:49 EDT),
covering everything from initial investigation through full rebuild,
live testing of every component, backup, documentation, and publishing
the corrected setup script back to GitHub.

## Situation

The laptop `ham-mintsauce` had been wiped back to a stock Linux Mint 22.3
install. The prior fully-configured ham radio + SDR build (hostname
`ham-mint` at the time) had been deleted to the external drive's own Trash
along with its backup scripts, then superseded by a fresh, empty backup.
The goal was to get this machine back to full working order using the
recovered old backup and the `mint-sauce-for-ham` project script, without
resorting to a risky full-root restore onto a live system.

## Approach

Rather than extracting the 18GB full-root backup over the live filesystem
(which the backup's own restore script explicitly warns against doing on a
booted system), the machine was rebuilt in place using
`mint-sauce-for-ham/Setup_Ham_Radio_Stack.sh` — a config-driven, idempotent
provisioning script recovered from the old backup's trash — combined with
installer files and personal station details recovered from the same
backup and from a station-info reference document.

## What was built

- **ADS-B / SDR reception**: RTL-SDR, readsb, tar1090 (live map), gpsd
  (USB GPS auto-detect), SDR++ with VHF/UHF and HF/Shortwave mode-switch
  shortcuts, and the official ADS-B Exchange feed + MLAT client.
- **IC-705 digital modes stack**: VarAC, VARA HF, VARA FM (all under a
  32-bit Wine prefix with Wine Mono for VarAC's .NET runtime), Pat Winlink
  (HF and FM), WSJT-X, JS8Call, and GridTracker — all sharing the radio via
  a single Hamlib `rigctld` bridge (flrig is used only for VarAC's PTT/CAT
  path, kept separate per a documented prior stability issue).
- **Station identity**: callsign N0CALL, grid AA00aa, Winlink and VARA
  registration configured from recovered station-info.
- **Conky station-status monitor**: live radio frequency and mode (USB,
  LSB, CW, USB-D, etc.), checking both rigctld and flrig so it stays
  accurate no matter which app currently has the radio; JS8Call/Pat
  running status; GPS-derived grid square; CPU temperature; UTC/local
  time and date — styled with a dark panel, section headers, and a blue
  accent color, with autostart on login.
- **10-minute station ID timer**: a small always-on-top utility with
  Start/Cancel buttons, sized and colored to match Conky and positioned
  directly under it, that beeps and flashes at each 10-minute mark and
  auto-repeats until cancelled — also autostarts.
- **A full system backup** of the finished machine to the external drive,
  plus this synopsis and a companion detailed step-by-step document.
- **The `mint-sauce-for-ham` GitHub repository refreshed** to match this
  build: the two real bugs found below were fixed directly in
  `Setup_Ham_Radio_Stack.sh` (along with proactively installing `flrig`
  and Wine Mono, and auto-repointing VarAC's Desktop shortcut through
  `Start_VarAC.sh`), the README updated with a fresh-install verification
  note, the old 3-commit history squashed into a single clean commit and
  force-pushed, and the repo's description and topics
  (`ham-radio`, `sdr`, `ic-705`, `linux-mint`, `wine`, `ads-b`, `winlink`)
  updated to reflect this verified build rather than the earlier trial
  version. No personal information (callsign, grid, credentials) was ever
  present in any commit — verified by searching the full history before
  publishing.

## Notable issues found and fixed along the way

- Wrong package name (`hamlib-utils` → `libhamlib-utils`) blocked the
  first provisioning pass.
- The user account was missing from the `dialout` group, so nothing could
  open the IC-705's or the GPS's serial ports until that was fixed and the
  machine rebooted.
- VarAC (a .NET application) requires Wine Mono, which isn't installed by
  the base Wine package or any winetricks verb in newer Wine — it had to
  be downloaded and installed directly from WineHQ.
- The ADS-B Exchange feed had been brought up under the wrong feeder name
  (`EE-KPNE` instead of the documented `EE-KPHL`) and was corrected.
- VARA FM's registration code and audio device were not carried over
  automatically when VARA HF's were (the automated config step ran before
  a registration code was available) and had to be patched in afterward.
- VarAC's Wine-hosted Save dialog throws a false "backup directory does
  not exist" error on every settings save under Wine, even though the
  underlying save (verified via file timestamps) succeeds correctly every
  time — treated as a cosmetic, safe-to-ignore Wine quirk.
- `readsb` was left stopped after SDR++ testing (the SDR++ mode-switch
  scripts stop it to free the shared RTL-SDR dongle) and had to be
  restarted before ADS-B would work again.

## Final status

Every component was individually tested live and confirmed working:
ADS-B tracking and Exchange feeding, both SDR++ modes, VarAC, VARA HF/FM,
Pat Winlink HF/FM, WSJT-X, JS8Call, GridTracker, the Conky monitor
(including its mode display), and the full 10-minute ID timer cycle. The
finished machine was fully backed up to this drive, this synopsis and the
detailed step-by-step document were written alongside it, and the
`mint-sauce-for-ham` GitHub repository now reflects this exact, verified
build.
